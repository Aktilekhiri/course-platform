# NextGen AI Academy — дизайн (Nova Glass)

Статичные HTML-страницы без бизнес-логики. Открывайте `index.html`.

- `index.html` — лендинг
- `course.html` — страница курса (программа, «Чему вы научитесь», CTA)
- `dashboard.html` — кабинет студента
- `lesson.html` — видеоурок
- `admin-review.html` — проверка проектов (ручное подтверждение)
- `certificate.html` — сертификат

Тёмная/светлая тема и RU/EN переключаются кнопками в шапке (хранятся в localStorage).
Данные на страницах — демо. Шрифты Unbounded и Onest (SIL OFL) лежат в `assets/fonts`.
